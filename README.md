# مطبعجي فايبر ليزر — V7.3.0 Wallet Target

نسخة مبسطة موجهة للوصول إلى شكل أقرب للنقش المرجعي على الجلد:
- **بورتريه محفظة**: جلد أبيض تقريبًا، نويز خفيف جدًا، وإبراز التفاصيل فقط.
- **عين محفظة**: ناتج مستطيل بدون قص تلقائي للناتج النهائي، مع إبراز العين والحاجب والرموش.

## ما الجديد
- تقليل الواجهة إلى مسارين أساسيين فقط.
- اختيار سريع للبورتريه: ناعم / متوسط / أوضح.
- اختيار سريع للعين: ناعم / متوسط / أوضح.
- افتراضيًا يتم استخدام **AI Wallet Sketch** للبورتريه.
- افتراضيًا يتم استخدام **Wallet Eye** مع كثافة خفيفة للعين.
- تم إلغاء قص ناتج العين النهائي، ليظل مستطيلاً.
