نسخة V5.7.0
============

قبل أي رفع:
1) شغّل npm test
2) شغّل npm run build:single

النسخة العامة التجريبية:
- index.html
- demo.html
- app.js
- styles.css
- update-config.js
- version.json
- README.md
- CHANGELOG.md
- .nojekyll

أي تشغيل من موقع عام سيعمل Demo تلقائيًا، حتى إذا حذف الزائر ?demo=1.

النسخة الكاملة:
- أنشئ ZIP خاصًا من نفس الملفات بعد الاختبار.
- لا تضع رابط ZIP العام داخل version.json.
- افتح index.html محليًا، أو شغّل localhost للحصول على أفضل توافق مع موديلات AI.

علامة نجاح التحديث: أعلى الصفحة يظهر V5.7.0 و ACCURATE SIZE.
