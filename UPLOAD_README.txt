نسخة V6.0.0
============

قبل أي رفع:
1) شغّل npm test
2) شغّل npm run build:single

ملفات الإصدار الكامل:
- index.html
- app.js
- styles.css
- update-config.js
- version.json
- README.md
- CHANGELOG.md
- .nojekyll

لا يوجد وضع تجريبي. التشغيل المحلي والموقع العام يفتحان نفس الإصدار الكامل.

- أنشئ ZIP من نفس الملفات بعد الاختبار.
- افتح index.html محليًا، أو شغّل localhost للحصول على أفضل توافق مع موديلات AI.

علامة نجاح التحديث: أعلى الصفحة يظهر V6.0.0 و CALIBRATED PHOTO، وتظهر بطاقة «معمل المعايرة» في الصفحة الرئيسية.
