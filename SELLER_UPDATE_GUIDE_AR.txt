دليل تحديث البرنامج — V7.2.0
=================================

- البرنامج إصدار كامل فقط ويعمل محليًا أو على GitHub Pages بدون Demo.
- عند إصدار تحديث: غيّر APP_VERSION، روابط الإصدار في index.html، وversion.json.
- اترك downloadUrl فارغًا أو ضع رابط HTTPS خاصًا بالعملاء.
- نفّذ npm test ثم npm run build:single.
- أنشئ ZIP مسطحًا من ملفات التشغيل؛ لا تضع فولدر المصدر داخل ZIP.
- ارفع ملفات الموقع المفكوكة إلى جذر main، وليس ZIP وحده.

المحرك الجديد يعتمد على موديل Line-Art مفتوح المصدر يُحمّل عند أول استخدام، ومعه XDoG محلي احتياطي. حافظ على THIRD_PARTY_NOTICES.txt ضمن الحزمة.

الملفات الأساسية:
- index.html
- app.js
- styles.css
- update-config.js
- version.json
- THIRD_PARTY_NOTICES.txt

زر «فحص التحديث» يقارن النسخة المثبتة بـversion.json المنشور.
