دليل تحديث البرنامج — V6.0.0
=================================

مهم جدًا:
- البرنامج إصدار كامل فقط.
- التشغيل من GitHub Pages أو محليًا أو من localhost يقدم الوظائف نفسها دون علامة مائية أو قفل للتصدير.

عند إصدار تحديث جديد:
1) غيّر APP_VERSION في app.js.
2) غيّر رقم النسخة في عنوان وروابط index.html.
3) غيّر version وtitle وnotes داخل version.json.
4) ضع رابط تنزيل HTTPS خاص بالعملاء في downloadUrl، أو اتركه فارغًا ليطلب العميل النسخة من البائع.
5) نفّذ: npm test
6) نفّذ: npm run build:single
7) أنشئ ZIP للإصدار الكامل.
8) ارفع ملفات الإصدار الكامل إلى الموقع عند الحاجة.

الملفات الأساسية التي تعدّلها:
- index.html
- app.js
- styles.css
- update-config.js
- version.json

لا تعدّل ملفات app.v561.js أو app.v562.js القديمة؛ يمكن حذفها من أي إصدار جديد.

العميل يضغط «فحص التحديث» داخل برنامجه. لو الرقم المنشور أحدث، يظهر رابط التنزيل الخاص عند توفره.

ملاحظة:
JavaScript داخل المتصفح لا يوفر ترخيصًا تجاريًا غير قابل للكسر. لو مطلوب تفعيل بجهاز العميل وتحديث صامت، انقل النسخة لاحقًا لتطبيق Desktop موقّع مع خادم تراخيص.
